# Личные интеграции, задачи и Telegram-уведомления

## Цель
Сделать рабочие личные подключения внешних сервисов для каждого пользователя, исправить истекшую авторизацию Google Drive, добавить безопасное удаление задач и адресные Telegram-уведомления исполнителям.

## Что будет реализовано

### 1. Google Drive
- Убрать доступ к Drive другого участника пространства: каждый пользователь читает и изменяет только свой подключенный Google Drive.
- Распознавать ошибку `credential_refresh_token_expired`, очищать недействительное подключение и показывать понятную кнопку «Подключить заново» вместо технического JSON.
- Сохранить чтение Google Docs и всех листов Google Sheets, создание документов и список файлов.
- Добавить в карточку раскрываемую методичку: создание/настройка Google OAuth, разрешения, подключение, переподключение и отключение.

### 2. Новые личные интеграции
- Реализовать реальные App User Connector-подключения для:
  - Notion — страницы, базы и поиск по доступному контенту;
  - Slack — каналы, сообщения и поиск в разрешенной области;
  - Microsoft OneDrive — файлы и папки пользователя.
- Для каждого сервиса добавить полноценную карточку: статус, подключить/переподключить/отключить, краткий список доступных данных и встроенную пошаговую методичку.
- Использовать существующее зашифрованное серверное хранилище ключей, отдельную запись на пользователя и сервис.
- После подключения включить данные сервисов в контекст AI-чата только текущего пользователя и активного рабочего пространства.

### 3. Dropbox
- В текущем каталоге App User Connectors Dropbox отсутствует, поэтому готовое безопасное личное OAuth-подключение сейчас недоступно.
- Добавить честную карточку Dropbox со статусом «Требуется настройка» и методичкой для будущего custom OAuth, без фиктивной кнопки подключения.
- Не запрашивать Dropbox Client ID/Secret до создания callback-инфраструктуры и отдельного подтверждения custom OAuth.

### 4. Задачи и исполнители
- Добавить к задаче стабильный `assignee_id`, сохранив `assignee_name` для отображения и совместимости старых задач.
- Заменить свободный ввод исполнителя на выбор реального участника активного пространства.
- Перенести создание, редактирование, смену статуса и удаление в защищенные серверные функции с проверкой членства в пространстве.
- Оставить удаление в меню и форме задачи, но добавить подтверждение перед безвозвратным удалением и корректный откат интерфейса при ошибке.
- Обновить AI/MCP-создание задач так, чтобы оно использовало тот же безопасный путь и не обходило уведомления.

### 5. Telegram-уведомления
- При назначении задачи отправлять сообщение Telegram именно назначенному участнику, если он связал Telegram с Virtual Space.
- При изменении статуса, срока, приоритета, описания или переназначении отправлять исполнителю краткое уведомление с названием задачи, пространством и изменениями.
- Сохранить ежедневные уведомления о задачах и приближающихся дедлайнах; ограничить их активным пространством и назначенным пользователем.
- Если Telegram не подключен, задача сохраняется без ошибки; интерфейс показывает, что уведомление не доставлено из-за отсутствия связи.

## Интерфейс и локализация
- Все новые состояния, ошибки, подтверждения, инструкции и кнопки добавить на русском и английском.
- Использовать текущие компоненты и дизайн-токены; технические ответы коннекторов пользователю не показывать.
- Исправить светлую тему интеграций, где сейчас применены жесткие белые цвета.

## Технические изменения
- Миграция: `tasks.assignee_id uuid NULL`, индекс по исполнителю; внешний ключ на управляемую auth-схему не добавлять.
- RLS и серверная проверка: назначать можно только участника той же команды; удалять/изменять — только в доступном активном пространстве.
- Общий серверный слой для OAuth-коннекторов и единая обработка состояний `connected`, `needs_reauth`, `disconnected`.
- OAuth-клиенты Notion, Slack и OneDrive нужно связать через workspace App User Connectors; если клиент еще не создан, соответствующая карточка настройки будет запрошена во время реализации.

## Проверка
- Проверить личную изоляцию интеграций между двумя пользователями и между рабочими пространствами.
- Проверить повторную авторизацию Drive после просроченного токена.
- Проверить подключение, чтение и отключение Notion, Slack и OneDrive.
- Проверить создание, редактирование, перенос и подтвержденное удаление задач.
- Проверить Telegram: назначение, изменение, дедлайн, пользователь без подключенного Telegram.
- Проверить мобильную/десктопную версию, светлую/темную тему и RU/EN.
