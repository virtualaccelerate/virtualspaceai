# Интеграция задач с YouGile

## Результат
YouGile становится основным таск-трекером для рабочего пространства. Virtual Space хранит синхронизированную копию задач только для Telegram-уведомлений, напоминаний, ежедневных и вечерних отчётов. На странице задач редактирование и создание отключаются для подключённого пространства.

Из Telegram сотрудник сможет нажать «Начать» или изменить статус; Virtual Space отправит изменение в YouGile и только после успешного ответа обновит локальную копию.

## Что будет сделано
- В разделе «Интеграции» добавить YouGile с подключением по API-ключу и выбором одного проекта.
- Безопасно хранить ключ отдельно для каждого рабочего пространства; показывать только состояние подключения, без раскрытия ключа.
- При подключении загрузить проект, доски, колонки, пользователей и задачи; сопоставить колонки YouGile со статусами Virtual Space.
- Добавить настройку соответствия сотрудников YouGile участникам пространства по email, с ручным выбором для несовпавших пользователей.
- Добавить защищённый адрес для событий YouGile и регистрацию событий создания, изменения, перемещения и удаления задач.
- Добавить периодическую сверку, чтобы восстанавливать пропущенные события и обновлять задачи без дублей.
- Сохранять внешний ID, ссылку, проект, доску, колонку, исполнителя, приоритет, дедлайн и время изменения задачи.
- Отправлять существующие Telegram-уведомления и включать задачи YouGile в утренние/вечерние отчёты и напоминания.
- Кнопки Telegram будут менять статус в YouGile; при ошибке статус останется прежним и сотрудник увидит понятное сообщение.
- В интерфейсе задач показать режим «Управляется в YouGile», ссылку на исходную задачу и время последней синхронизации.

## Технические детали
- Новая таблица подключения YouGile с RLS и зашифрованным API-ключом; доступ к настройкам только владельцу и администратору пространства.
- Поля внешней синхронизации в задачах и уникальность `(teamspace_id, external_source, external_id)` для идемпотентного обновления.
- Публичный webhook проверяет уникальный секрет пространства до любых изменений; повторные события безопасны.
- Первичная синхронизация и сверка используют пагинацию и лимит YouGile 50 запросов в минуту.
- Сопоставление статусов задаётся по колонкам выбранного проекта; завершённые задачи определяются также по `completed`.
- Удалённые в YouGile задачи архивируются в локальной копии и исключаются из активных уведомлений и отчётов.

## Проверка
- Подключение, выбор одного проекта и первичный импорт без дублей.
- Создание, перенос, изменение дедлайна/исполнителя и удаление задачи в YouGile отражаются в Virtual Space.
- «Начать» и смена статуса в Telegram успешно обновляют YouGile.
- Назначение, дедлайн, просрочка, утренний и вечерний отчёты приходят по синхронизированным задачам.
- Недоступный ключ, лимит API и повторный webhook не ломают задачи и показывают состояние синхронизации.
