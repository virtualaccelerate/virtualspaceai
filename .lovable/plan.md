# Google Calendar: личные календари, задачи и встречи

## Что получат пользователи
- В «Интеграциях» появится Google Calendar. Каждый участник подключает собственный Google-аккаунт; доступ одного пользователя не используется другим.
- Задача с дедлайном автоматически создаёт событие в календаре ответственного, если его календарь подключён.
- Изменение названия, описания, дедлайна, статуса или ответственного обновляет связанное событие. Завершённая задача помечается выполненной, удалённая — удаляется из календаря.
- Изменение даты связанного события в Google Calendar обновляет дедлайн задачи в Virtual Space. Синхронизация запускается автоматически и также вручную из карточки интеграции.
- Команды в AI-чате вроде «Создай встречу с Айзой завтра в 15:00 на час» создают событие в личном календаре автора и добавляют найденных участников по email. Если даты, времени или участника не хватает, AI задаёт один короткий уточняющий вопрос.

## Интерфейс
- Карточка Google Calendar показывает подключённый аккаунт, выбранный календарь, последнюю синхронизацию, ошибки, кнопки «Синхронизировать», «Переподключить» и «Отключить».
- После подключения пользователь выбирает календарь; по умолчанию используется основной.
- Результат создания встречи отображается в чате со ссылкой «Открыть в Google Calendar».

## Безопасность и данные
- Ключ подключения каждого пользователя хранится только на сервере в зашифрованном виде.
- Добавится таблица связей между задачами/встречами и Google-событиями; доступ к ней будет только у серверной части.
- Все операции проверяют текущего пользователя, его участие в workspace и принадлежность задачи.
- OAuth использует отдельный Google Calendar connector и только необходимые Calendar/profile scopes.

## Технические детали
- Добавить OAuth return-страницу, server functions и отдельный Google Calendar server-модуль по существующему Google Drive паттерну.
- Добавить миграцию для `google_calendar_links` с явными GRANT для `service_role`, RLS без клиентских политик, уникальностью пользователя/задачи/события и полями sync token/etag/last sync/error.
- Централизовать push-sync в task create/update/delete, а Telegram перевести на те же task helpers, чтобы задачи из обоих чатов синхронизировались одинаково.
- Добавить AI-директиву встречи с серверной проверкой даты, времени, timezone и email участников; выполнить её только по явной просьбе пользователя.
- Для обратной синхронизации использовать Google Calendar incremental sync в защищённом периодическом проходе; внешние YouGile/Trello задачи не изменять.
- Добавить локализованные тексты для RU/EN/KY/KK/UZ/TG и метаданные OAuth return-страницы.

## Проверка
- Подключение/переподключение/отключение личного календаря.
- Создание, перенос, завершение, переназначение и удаление локальной задачи.
- Обновление даты события в Google и возврат нового дедлайна в задачу.
- Создание встречи из чата с участником и без обязательных деталей.
- Регрессия YouGile, Trello, Telegram-задач и существующего календарного ICS-фида.
