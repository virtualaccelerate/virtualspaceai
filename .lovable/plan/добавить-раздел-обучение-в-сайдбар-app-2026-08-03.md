# Добавить раздел «Обучение» в сайдбар /app

## Что делаем
Добавить в левый сайдбар приложения новый пункт «Обучение» (Learning) сразу после «Телеграм». Пункт ведёт на новую страницу `/app/learn`.

## Изменения

### 1. Новая страница — `src/routes/_authenticated/app.learn.tsx`
- Создать маршрут `/app/learn` внутри `_authenticated` layout.
- Страница показывает заголовок «Обучение» и карточки-заглушки для будущих материалов (курсы, менторы, база знаний) в едином стиле приложения.
- Использовать `createFileRoute("/_authenticated/app/learn")`.

### 2. Сайдбар — `src/routes/_authenticated/route.tsx`
- Импортировать иконку `GraduationCap` из `lucide-react`.
- Добавить объект `{ to: "/app/learn", label: t("app.nav.learn"), icon: GraduationCap }` в массив `afterNav` после Telegram.
- Убедиться, что пункт отображается в свёрнутом и развёрнутом виде сайдбара, а также активируется на `/app/learn`.

### 3. Локализация — `src/lib/i18n.ts`
- Добавить ключ `app.nav.learn` для всех 6 языков:
  - en: "Learning"
  - ru: "Обучение"
  - kk: "Оқыту"
  - ky: "Окутуу"
  - uz: "O‘qitish"
  - tg: "Омӯзиш"
- Добавить базовые строки для страницы learn (title, subtitle, карточки) в каждый язык.

### 4. Мобильная навигация
- Пункт «Обучение» добавляется только в сайдбар, как и просили. Нижний мобильный навбар остаётся без изменений (там 5 основных пунктов).

## Что НЕ делаем
- Не создаём backend-таблиц и не реализуем полноценную LMS.
- Не меняем структуру других разделов сайдбара, кроме добавления одного пункта.
